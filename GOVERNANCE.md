# Governance

The founder is the initial sole maintainer and merger. Changes to protocol,
serialization, identity, Session, channels, security, or the public API require
maintainer review and conformance tests. Contributors work through forks and
pull requests. No CLA is used; DCO 1.1 sign-off is required.

Additional maintainers may be appointed after sustained, trusted contribution.
Relicensing requires permission from affected copyright holders.
