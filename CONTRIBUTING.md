# Contributing

Discuss protocol, wire, public API, channel, dependency, or security-sensitive
changes before implementation. Smaller fixes may go directly to a pull request.

Every commit must include a `Signed-off-by:` line certifying the Developer
Certificate of Origin 1.1: <https://developercertificate.org/>. Contributors
retain copyright; contributions are submitted under this repository's license.
There is no CLA.

Run `python -m pytest -q` and describe compatibility, security, persistence, and
licensing effects in the pull request.
